How to export a Sitecore package

Exporting the Banners tree from Sitecore

The upload on the portal home page expects a Sitecore package ZIP that contains the Mijn Essent\SBS\Banners (or Mijn EnergieDirect\SBS\Banners) tree together with its linked media items. Follow the five steps below in the Sitecore Content Editor to create that package.

  1. 1

    Start a new package

    In the content tree, right-click the Banners folder under SBS. Choose Packaging and then Start New Package.

  2. 2

    Add the whole tree to the package

    In the Starting New Package dialog select Add Tree to Package and click Add. This includes the Banners folder and every banner item below it.

  3. 3

    Set the installation options

    Check that the item root is master:\content\Mijn Essent\SBS\Banners. Use Root and descendants, installation option Merge - Merge, and under Include linked Items choose Include all linked items. Click OK.

    "Include all linked items" is what pulls the banner images from the media library into the package. Without it the previews have no images.

  4. 4

    Select the linked items

    Sitecore lists the linked items per tab: Content, Media, System and Templates. Use Select all on each tab so all of them are included, then continue.

  5. 5

    Download the package

    Right-click the Banners folder again, choose Packaging and then Download Package. Save the ZIP and drop it on the upload area of the portal home page.
